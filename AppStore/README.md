# QuickLaunch - App Store Materials

This directory contains all the materials needed for App Store submission.

## Screenshots

Screenshots should be taken at the following resolutions for macOS apps:
- 1280 x 800 (16:10 aspect ratio)
- 1440 x 900 (16:10 aspect ratio)
- 2560 x 1600 (16:10 aspect ratio)

### Required Screenshots (3-10 images):
1. **Main Interface** - Full application view showing the app grid
2. **Search Functionality** - App with search bar active and filtering results
3. **App Launch** - Demonstration of launching an application
4. **Drag and Drop** - Showing the drag and drop reordering functionality
5. **Context Menu** - Right-click context menu options
