# Screenshot Guide for QuickLaunch

## Overview
This guide provides instructions for creating high-quality App Store screenshots for QuickLaunch.

## Required Screenshots (3-10 images needed)

### 1. Main Interface Screenshot
**Filename**: `screenshot_1_main_interface.png`
**Description**: Full application view showing the app grid
**Instructions**:
- Launch QuickLaunch (ESC key or from Applications)
- Ensure the app shows a full grid of applications
- Take screenshot showing the complete interface
- Should demonstrate the clean, organized layout

### 2. Search Functionality Screenshot
**Filename**: `screenshot_2_search.png`
**Description**: App with search bar active and filtering results
**Instructions**:
- Launch QuickLaunch
- Click in the search bar at the top
- Type a common search term (e.g., "Saf" for Safari)
- Show filtered results
- Capture the real-time search filtering in action

### 3. App Launch Demonstration
**Filename**: `screenshot_3_launch_app.png`
**Description**: Showing an app being launched or just launched
**Instructions**:
- Have QuickLaunch open
- Hover over a popular application icon (like Safari, Chrome, etc.)
- Show the hover state with scaling effect
- Alternatively, capture right after clicking to show the launch action

### 4. Drag and Drop Functionality
**Filename**: `screenshot_4_drag_drop.png`
**Description**: Demonstrating drag and drop reordering
**Instructions**:
- Open QuickLaunch
- Start dragging an application icon
- Show the drag state with the semi-transparent dragged item
- Display other apps shifting to make room
- Capture the visual feedback during drag operation

### 5. Context Menu
**Filename**: `screenshot_5_context_menu.png`
**Description**: Right-click context menu options
**Instructions**:
- Right-click on any application in QuickLaunch
- Show the context menu with options:
  - Open
  - Show in Finder
  - Get Info
- Capture the menu in a clear, readable state

## Technical Requirements

### Resolution Guidelines
Primary screenshots should be taken at:
- **2560 x 1600** (Retina displays) - Preferred
- **1440 x 900** (Standard high-res) - Acceptable
- **1280 x 800** (Minimum) - Fallback

### Image Specifications
- **Format**: PNG (preferred) or JPEG
- **Color Space**: sRGB
- **File Size**: Under 8MB per image
- **Aspect Ratio**: 16:10 (standard for Mac screenshots)

### Quality Guidelines
- Ensure clear, sharp images without blur
- Use good lighting conditions for screen capture
- Avoid overexposed or underexposed areas
- Show realistic app content (actual installed applications)
- Ensure all text is legible

## Screenshot Setup Tips

### Before Taking Screenshots:
1. **Clean up your app collection**: Remove any inappropriate or personal apps
2. **Organize layout**: Arrange popular, recognizable apps prominently
3. **Check display settings**: Use native resolution for sharpest quality
4. **Close other applications**: Minimize distractions and ensure QuickLaunch has focus

### Recommended Apps to Show:
Include recognizable, family-friendly applications such as:
- Safari, Chrome, Firefox (Web browsers)
- Mail, Messages (Communication)
- Photos, Preview (Media viewers)
- TextEdit, Pages (Productivity)
- App Store, System Preferences (System apps)
- Calculator, Calendar (Utilities)

### Apps to Avoid:
- Personal or sensitive applications
- Development tools (unless targeting developers)
- Adult content or mature applications
- Unfamiliar or niche applications most users won't recognize

## Taking the Screenshots

### Method 1: Built-in macOS Screenshot Tool
1. Press `Cmd + Shift + 4`
2. Press `Spacebar` to switch to window capture mode
3. Click on QuickLaunch window
4. File will be saved to Desktop

### Method 2: Screenshot App
1. Open Screenshot app (Applications > Utilities)
2. Choose "Capture Selected Window"
3. Select QuickLaunch window
4. Save with appropriate filename

### Method 3: Preview Method
1. Open QuickLaunch
2. Press `Cmd + Shift + 3` for full screen
3. Open in Preview and crop to show just QuickLaunch

## Post-Processing (Optional)

### Basic Enhancements:
- Adjust brightness/contrast if needed
- Crop to remove unnecessary borders
- Ensure consistent sizing across all screenshots
- Add subtle drop shadow if desired (macOS standard)

### What NOT to do:
- Don't heavily manipulate or alter the interface
- Don't add fake UI elements
- Don't include misleading content
- Don't over-saturate colors
